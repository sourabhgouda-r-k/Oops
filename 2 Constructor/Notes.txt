===============================
CONSTRUCTORS IN JAVA
===============================

A constructor is a special method in Java that is used to initialize objects.

It is automatically called when an object is created.


-----------------------------------
WHY CONSTRUCTORS ARE USED?
-----------------------------------

Constructors help to:
- initialize object values
- assign default values
- reduce repeated code
- make object creation easier


-----------------------------------
IMPORTANT FEATURES OF CONSTRUCTOR
-----------------------------------

1. Constructor name must be same as class name
2. Constructor does not have return type
3. Constructor is automatically called
4. Constructor is mainly used for object initialization


-----------------------------------
BASIC SYNTAX
-----------------------------------

class Student {

    Student() {

    }
}


-----------------------------------
EXAMPLE PROGRAM
-----------------------------------

class Student {

    Student() {
        System.out.println("Constructor Called");
    }
}

public class Main {

    public static void main(String[] args) {

        Student s1 = new Student();
    }
}


OUTPUT:
Constructor Called


===================================
TYPES OF CONSTRUCTORS
===================================

1. Default Constructor
2. No-Argument Constructor
3. Parameterized Constructor


===================================
1. DEFAULT CONSTRUCTOR
===================================

A constructor automatically created by Java compiler if programmer does not create any constructor.


EXAMPLE:

class Student {

    int id;
    String name;
}

public class Main {

    public static void main(String[] args) {

        Student s1 = new Student();

        System.out.println(s1.id);
        System.out.println(s1.name);
    }
}


OUTPUT:
0
null


-----------------------------------
DEFAULT VALUES IN JAVA
-----------------------------------

int       -> 0
float     -> 0.0
double    -> 0.0
boolean   -> false
char      -> '\u0000'
String    -> null


===================================
2. NO-ARGUMENT CONSTRUCTOR
===================================

A constructor created by programmer without parameters.


EXAMPLE:

class Student {

    Student() {
        System.out.println("No-Argument Constructor");
    }
}

public class Main {

    public static void main(String[] args) {

        Student s1 = new Student();
    }
}


OUTPUT:
No-Argument Constructor


===================================
3. PARAMETERIZED CONSTRUCTOR
===================================

A constructor that accepts values or arguments.

Used to initialize objects with different data.


EXAMPLE:

class Student {

    int id;
    String name;

    Student(int i, String n) {

        id = i;
        name = n;
    }

    void display() {

        System.out.println(id + " " + name);
    }
}

public class Main {

    public static void main(String[] args) {

        Student s1 = new Student(101, "Ram");

        s1.display();
    }
}


OUTPUT:
101 Ram


===================================
CONSTRUCTOR OVERLOADING
===================================

Creating multiple constructors with different parameters in same class.


EXAMPLE:

class Student {

    Student() {

        System.out.println("Default Constructor");
    }

    Student(String name) {

        System.out.println(name);
    }

    Student(int age) {

        System.out.println(age);
    }
}

public class Main {

    public static void main(String[] args) {

        Student s1 = new Student();

        Student s2 = new Student("Ram");

        Student s3 = new Student(20);
    }
}


OUTPUT:
Default Constructor
Ram
20


===================================
THIS KEYWORD IN CONSTRUCTOR
===================================

this keyword refers to current object.

Used when local variables and instance variables have same name.


EXAMPLE:

class Student {

    int id;
    String name;

    Student(int id, String name) {

        this.id = id;
        this.name = name;
    }

    void display() {

        System.out.println(id + " " + name);
    }
}

public class Main {

    public static void main(String[] args) {

        Student s1 = new Student(1, "Sam");

        s1.display();
    }
}


OUTPUT:
1 Sam


===================================
CONSTRUCTOR CHAINING
===================================

Calling one constructor from another constructor in same class.

Done using:
this();


EXAMPLE:

class Student {

    Student() {

        this(100);

        System.out.println("Default Constructor");
    }

    Student(int x) {

        System.out.println(x);
    }
}

public class Main {

    public static void main(String[] args) {

        Student s1 = new Student();
    }
}


OUTPUT:
100
Default Constructor


===================================
RULES OF CONSTRUCTORS
===================================

1. Constructor name must match class name

Correct:
class Student {

    Student() {

    }
}


Wrong:
class Student {

    Demo() {

    }
}


-----------------------------------

2. Constructor cannot have return type

Wrong:
void Student() {

}


-----------------------------------

3. Constructor can be overloaded

Allowed


-----------------------------------

4. Constructor is called automatically

No need to call manually.


===================================
DIFFERENCE BETWEEN METHOD AND CONSTRUCTOR
===================================

CONSTRUCTOR:
- Same name as class
- No return type
- Called automatically
- Used for initialization

METHOD:
- Can have any name
- Has return type
- Called manually
- Used for operations


===================================
REAL-LIFE EXAMPLE
===================================

Think constructor like filling admission form.

When a student joins college:
- name
- id
- course

are initialized immediately.

Same way constructor initializes object data when object is created.


===================================
MEMORY REPRESENTATION
===================================

Student s1 = new Student();

- Object created in heap memory
- Constructor initializes values
- Reference stored in stack memory


===================================
IMPORTANT INTERVIEW QUESTIONS
===================================

Q1. Can constructor be private?
Yes

Used in Singleton class.


-----------------------------------

Q2. Can constructor be static?
No

Because constructors belong to objects.


-----------------------------------

Q3. Can constructor return value?
No

Not even void.


-----------------------------------

Q4. Are constructors inherited?
No

Constructors are not inherited.

ADVANTAGES OF CONSTRUCTORS
===================================

1. Automatic initialization
2. Cleaner code
3. Better readability
4. Reusability


===================================
SUMMARY
===================================

1. Constructor is special method used for initialization.
2. Constructor name must match class name.
3. Constructor has no return type.
4. Constructors are automatically called.
5. Types:
   - Default Constructor
   - No-Argument Constructor
   - Parameterized Constructor
6. this keyword refers current object.
7. Constructor chaining uses this().
8. Constructors can be overloaded.
